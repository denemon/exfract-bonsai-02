# Grey-brown wood study — wood-v02

Actual local Three.js/WebGL implementation; **an editing study, not the finished premium garden**. Read `REPORT.md`, `INDEPENDENT-REVIEW.md` and `models/selection.json` for its limits.

- Preview: http://127.0.0.1:5194/ on this Mac only. Text-free scene. Small drag turns the real camera; wheel/pinch approaches; double click resets. Reduced motion suppresses gestures; idle rendering stops. Loading, missing WebGL and context loss show a still of the same scene.
- `site/` uses the already installed parent dependencies, pinned Three 0.185.1/Vite 8.2.2. Run `npm run build`, then `npm run preview`. Dev port is 5193. The local build references models/decoder/stills/bark through symlinks to avoid duplicate data; it is not a portable deployment archive.
- `models/wood-v02-editable.blend`: 2,314 editable controls, 2,312 faces, unapplied subdivision 1, branch/surface groups, inherited foliage/pot/stone, 12 hidden leaf LOD prototypes. All four original CC0 bark maps are packed. Native geometry/UVs reopen exactly. Native materials are an editing preview; `site/src/materials.js` is authoritative for the final color clamp, desaturation and relief.
- `models/wood-v02.glb`: selected compressed runtime geometry. `wood-v01/02/03.json` contain exact control positions, faces, masks, all UV loops and creases. All three were recreated and checked in Blender; v01/v03 remain rejected comparisons.
- `sculpt/surface-v02.py -- --version NEW_NAME` with Blender restores the protected stage5 basis in memory and regenerates this method into a new version. `surface.py` is the rejected v03 experiment. `surface-v01.py` and `material-v01.js` preserve the earlier failed direction. Do not blindly run historical scripts over existing deliverables. Future manual mesh edits should be saved to a new native file rather than overwritten by these recipes.
- `sculpt/save_native.py -- --version VERSION` packs maps and reopens a new native file from an existing compact record; it refuses to overwrite that output. `verify_restore.py` checks the three compact variants in memory.
- Bark: [Chinese Cedar Bark](https://polyhaven.com/a/chinese_cedar_bark), Charlotte Baglioni, [CC0](https://polyhaven.com/license). Original 1K JPEGs were verified against official API sizes/MD5 and retained unchanged. Runtime WebP maps total 375,600 bytes. `qa/bark-source.json` and `qa/bark-runtime-assets.json` retain provenance. No paid asset was purchased.
- `qa/final-production/` contains 46 checks and PC/390/320/tall/retina/loading/no-WebGL/context screenshots. `qa/final-performance/` has actual M1 Pro GPU timer measurements. These mobile sizes are Mac Chrome emulations, not physical devices.
- `site/public/still-manifest.json` links fallback images to model/material hashes and exact screenshot sources. `site/scripts/prepare_delivery.py --version wood-v02` regenerates them from retained screenshots. Refresh every fallback after any visual change.
- QA requires the single existing profile at `../local-structure-2122/qa/browser-profile` from the runs directory, acquires its `.active` lock, and must not overlap.
